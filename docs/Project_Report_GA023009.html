2.3 Security & Performance Guardrails

  • Zero-Hallucination Policy: The AI chatbot is restricted to verified knowledge documents. If a query falls outside the knowledge base, it explicitly declines to answer rather than fabricating credentials.
  • Credential Protection: All confidential API keys and SMTP credentials reside strictly in backend/.env and are excluded from git version control via .gitignore.
  • Bot Defense: Contact forms utilize honeypot trap fields invisible to human users, client-side email format regex, and server-side rate limiters.
  • WebGL Optimization: Dynamic Device Pixel Ratio clamping (DPR 1 to 1.5) ensures high framerates (60 FPS) on standard laptops and mobile devices.

Chapter 3: Detailed Module Implementation

3.1 Module 1: Responsive 3D Portfolio & Cinematic Navigation

The visual core of the application is a dark, futuristic 3D digital universe featuring glowing concentric rings, a central cyber pedestal, dynamic starry skyboxes, and volumetric accent lighting.

  • Section Structure: The single-page website organizes Sheryar's portfolio into 8 contiguous sections: #home, #about, #skills, #projects, #education, #video, #ai-assistant, and #contact.
  • Dynamic Scroll Camera Glide: Implemented in ScrollCameraController, the WebGL camera smoothly glides and tilts based on the user's scroll depth across the page.
  • Dark / Light Theme Toggle: A theme toggle button (☀️ / 🌙) in the navigation header allows visitors to instantly switch between the dark neon cosmos and an ultra-clean high-contrast light theme. State is saved to localStorage.
  • Mobile Drawer: An animated mobile hamburger menu provides seamless navigation across mobile phones and tablet viewports.

3.2 Module 2: Custom Blender 3D Avatar Integration

To fulfill the second module requirement, Sheryar Amir created a custom 3D avatar modeled in Blender, rigged, optimized, and exported in binary .glb format (frontend/public/models/avatar.glb).

  • Head Tracking: In Avatar3D.jsx, raycasting tracks the user's mouse position in normalized device coordinates, causing the avatar's head and neck bones to smoothly look toward the cursor.
  • Idle Breathing Motion: An organic continuous sine-wave oscillation animates the avatar's spine and chest, creating lifelike realism.
  • Click-to-Wave Interaction: Clicking on the 3D avatar triggers an inverse-kinematics arm-waving animation, plays an audio greeting chime synthesized via the Web Audio API, and displays an animated speech bubble stating: "Hello! I am Sheryar Amir. Welcome to my Developer's Universe!".

3.3 Module 3: 40-Second Promotional Motion Reel

Module 3 requires an embedded promotional motion graphics reel. Sheryar composited a 40-second promotional trailer rendered at 30 FPS in H.264 MP4 format with FastStart progressive streaming enabled (frontend/public/videos/promo-reel.mp4).

  • Custom Sci-Fi HUD Player: Rather than relying on default browser controls, an After Effects-themed video player was engineered in PromotionalVideoSection.jsx.
  • Player Controls: Interactive Play/Pause button, interactive scrub bar, exact timecode indicator (00:00 / 00:40), volume slider with mute toggle, restart shortcut, and fullscreen mode.

3.4 Module 4: Grounded AI Assistant (A.R.I.A.) & RAG Pipeline

Module 4 is implemented via A.R.I.A. (Autonomous Retrieval & Intelligence Assistant). The AI assistant is accessible through both an in-page full terminal (#ai-assistant) and an omnipresent floating HUD chat widget.

  • Source of Truth: Knowledge is ingested from knowledge_base.md, sheryar_cv.md, projects_knowledge.md, and academic_profile.md into 46 vectorized document chunks.
  • Disambiguation & Semantic Scorer: Built with multi-token fuzzy matching, English stop-word filtering, and domain-specific priority boosts. Specific queries (such as Blender projects vs. Game dev projects) are answered with 100% precision without mixing up domains.
  • Zero Hallucination: Answers are strictly confined to retrieved facts and cite their source documents directly.
