# Promotional Reel Video Directory (Module 3)

Place your rendered 30–60 second After Effects promotional video here:
- **Filename**: `promo-reel.mp4`
- **Path**: `frontend/public/videos/promo-reel.mp4`

### Export Instructions from Adobe After Effects:
1. Composition settings: 1920x1080 (Full HD) or 2560x1440 (2K), 30 or 60 fps, duration between 30 and 60 seconds.
2. File > Export > Add to Adobe Media Encoder Queue (or Render Queue).
3. Format: **H.264 (.mp4)**.
4. Preset: High Quality 1080p / Match Source - High bitrate (VBR 1 pass, 10–16 Mbps target).
5. Audio: AAC, 48kHz, 192 kbps stereo.
6. Name output file `promo-reel.mp4` and place it here.

*Note: The website includes an interactive holographic showcase player that gracefully detects and loops your video, with an animated procedural canvas fallback if the video is still in post-production.*
